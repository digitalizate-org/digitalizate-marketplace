## Why
[IDEO.org](http://ideo.org/)'s Human-Centered Design approach explicitly calls for 'co-create with communities' rather than simply designing for them, using participatory design methods to involve real users as active partners in the design process. As IDEO U describes, this requires a language shift from 'consult' to 'co-create.' For web applications, participatory design sessions — co-design workshops where users sketch interfaces, define features, and rank priorities — produce solutions with far higher adoption because users feel ownership of the outcome and designers eliminate assumptions before a pixel is placed.

## How to implement
- Run structured co-design workshops (90–120 minutes) with 5–8 target users — present the problem space, then invite users to sketch, annotate, and build low-fidelity interface concepts together
- Use MoSCoW prioritization (Must have, Should have, Could have, Won't have) collaboratively with users to align on what matters most before entering ideation
- Invite users to critique existing prototypes using structured prompts: 'What would you add?', 'What would you remove?', 'What would confuse you?'
- Include diverse participants — power users AND reluctant adopters, experienced AND novice users — to surface conflicting needs that must be reconciled in the design
- Use 'experience prototyping' — role-playing scenarios where users act out their workflow using paper mockups — to surface emotional and functional needs simultaneously
- Involve users at multiple stages: co-definition of the problem, co-ideation of solutions, co-evaluation of prototypes — not just a one-time input session

## Metrics
Applying this pattern can positively influence the following UX metrics:
- **Effectiveness**: Task success rate, Completion rate
- **Satisfaction & Perception**: NPS, CSAT, Ease-of-use score
- **Adoption & Retention**: Returning visitors, Account creation rate
**How to measure**: Compare task success rates and satisfaction scores for features designed with participatory methods against those designed without user co-creation. Track NPS over time to identify whether co-created features generate higher user advocacy, and monitor feature adoption rates in analytics.

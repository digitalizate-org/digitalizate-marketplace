## Why
People perceive and interpret ambiguous or complex images as the simplest possible form. In UX, this means designing icons using simple, immediately recognizable shapes; choosing the simplest chart type that communicates the insight (a bar chart over a radar chart for most comparisons); and removing visual chrome (borders, gradients, shadows) that doesn't carry semantic meaning. Complexity in visual presentation increases interpretation time, which compounds across thousands of daily interactions.

## How to implement
- Design icons using simple, immediately recognizable shapes — avoid decorative complexity in functional icons.
- Use the simplest chart type that communicates the insight (bar > complex radar for most comparisons; line > area for trend clarity).
- Remove visual chrome (borders, gradients, shadows) that doesn't carry semantic meaning.
- Use whitespace and clean typographic hierarchy rather than boxes around every element to create structure.
- Apply this to empty states, loading screens, and error messages — keep them unambiguous.

## Metrics
Applying this pattern can positively influence the following UX metrics:
- **Effectiveness**: Task success rate, Findability score
- **Efficiency**: Time on task, Completion time
- **Satisfaction & Perception**: Ease-of-use score, SUS score
**How to measure**: A/B test complex versus simplified visual representations for the same content and measure time-on-task and task success rate in usability sessions; collect SUS scores to gauge how simplification affects overall perceived usability.

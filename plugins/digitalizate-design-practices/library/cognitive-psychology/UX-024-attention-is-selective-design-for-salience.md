## Why
The brain aggressively filters visual and cognitive input, paying attention only to what it has been primed to notice, what appears salient against its background, or what matches prior expectations. Users will literally not see elements they have been trained to ignore — including banner ads, sidebar navigation after initial learning, and "always-on" status indicators that never change. This phenomenon explains why critical alerts placed in locations users have learned to ignore are ineffective. Use visual contrast, motion (one-shot, not looping), and proximity to primary focus to make critical information salient.

## How to implement
- Use visual contrast, single-shot animation, and proximity to primary focus to make critical information salient.
- Never rely on persistent always-visible elements for critical alerts — they will eventually be ignored.
- Use progressive interruption only for genuinely critical information that requires immediate action.
- For monitoring dashboards, use animation sparingly — a single flash indicating a value changed is more attention-getting than a constantly pulsing indicator.

## Metrics
Applying this pattern can positively influence the following UX metrics:
- **Effectiveness**: Task success rate, Findability score
- **Efficiency**: Time on task, Error counts
- **Satisfaction & Perception**: Ease-of-use score, Confidence rating
**How to measure**: Conduct first-click tests and eye-tracking studies to verify salient elements capture attention in the intended order; measure task success rate and time-to-first-correct-action in usability tests comparing high-salience versus low-salience designs.

## Why
Enterprise application views often need to be printed or exported as PDFs for audit trails, compliance reports, and executive briefings. Without print-specific stylesheets, enterprise dashboards and tables print with navigation chrome, truncated columns, and broken layouts that are unusable. Designing for print is not an afterthought — it is a compliance requirement in regulated industries and a workflow necessity in most enterprise contexts.

## How to implement
- Define `@media print` CSS: hide sidebar navigation, toolbars, and action buttons; expand all collapsed sections; break tables across pages appropriately; add a page header (company name, report name) and footer (generated by, timestamp, page number).
- Provide a "Print / Export PDF" button that opens a print-optimized view.
- Test on A4 and US Letter paper formats.
- For scheduled reports, generate server-side PDFs that exactly match the print view.

## Metrics
Applying this pattern can positively influence the following UX metrics:
- **Effectiveness**: Task success rate, Completion rate
- **Efficiency**: Time on task, Time saved per task
- **Satisfaction & Perception**: Ease-of-use score, CSAT
**How to measure**: Track print/export usage frequency via analytics and survey users on output quality satisfaction; measure time users spend post-export reformatting data as a proxy for whether exported format meets job requirements.

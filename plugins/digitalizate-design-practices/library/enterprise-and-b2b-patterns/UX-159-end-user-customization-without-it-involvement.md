## Why
Enterprise products requiring implementation specialists or IT configuration for every customization create dependency and frustration. Self-service customization — where users tailor the product to their own workflows — builds ownership, increases loyalty, and reduces support burden. This is a key differentiator between consumer-grade and legacy enterprise UX: consumer tools give users direct control; legacy tools route every change through IT or implementation services.

## How to implement
- Allow users to configure their own dashboard layouts, saved filters, column preferences, and notification settings.
- Support team-level customization that can be shared without IT involvement.
- Provide template libraries teams can clone and adapt.
- Make the product feel "made for them" through personalization — this is a documented adoption driver.
- Define clearly what can be self-configured by users, what requires admin access, and what requires IT — and minimize the last category.

## Metrics
Applying this pattern can positively influence the following UX metrics:
- **Effectiveness**: Task success rate, Completion rate
- **Efficiency**: Time on task, Time saved per task
- **Adoption & Retention**: Account creation rate, Returning visitors
- **Satisfaction & Perception**: Ease-of-use score, CSAT, NPS
**How to measure**: Survey enterprise users on satisfaction and perceived control after enabling self-service customization; track IT support tickets and time-to-configure before and after rollout. Monitor feature usage of customization options to assess adoption rates across user cohorts.

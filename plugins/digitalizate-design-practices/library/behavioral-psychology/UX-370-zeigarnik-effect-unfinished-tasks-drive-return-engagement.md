## Why
Soviet psychologist Bluma Zeigarnik discovered that incomplete tasks create a persistent cognitive tension that keeps them more accessible in memory than completed tasks — a phenomenon now called the Zeigarnik effect. In UX, this means that starting users on a journey creates a cognitive pull toward completion that outlasts the current session. This is why abandoned cart emails, 'Resume where you left off' prompts, and partially filled profile indicators are effective re-engagement mechanisms. The effect only works if users have genuinely started the task; it cannot create engagement from a cold start.

## How to implement
- Design explicit 'incomplete' states for partially finished tasks: 60% profile completion banners, abandoned carts, paused courses
- Send triggered re-engagement emails or notifications when users leave a high-value task incomplete (checkout abandonment, incomplete onboarding)
- Use persistent visual indicators (a partially-filled circle, a checklist with unchecked items) that are visible on the dashboard between sessions
- Leverage autoplay and infinite scroll patterns (where ethical) to leverage the 'always more' sense of incompletion
- Save user progress automatically and communicate it explicitly: 'We saved your work — pick up where you left off'
- Create engagement goals and badge systems that are intentionally always in-progress, never fully 'finished' (monthly challenges, level systems)

## Metrics
Applying this pattern can positively influence the following UX metrics:
  - **Engagement & Usage**: Sessions per user, Active users, Abandonment rate, Session frequency
  - **Adoption & Retention**: Returning visitors
  - **Effectiveness**: Completion rate
  **How to measure**: Track return-session rates for users with persisted incomplete task notifications vs. those without. Use funnel analytics to measure whether Zeigarnik-triggered re-entry prompts (emails, in-app nudges) improve multi-session completion rates.

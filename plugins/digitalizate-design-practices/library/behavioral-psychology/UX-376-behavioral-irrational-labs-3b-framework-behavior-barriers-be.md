## Why
Irrational Labs (Dan Ariely and Kristen Berman) developed the 3B framework as a practical behavioral design process: identify the single Key Behavior you want users to perform, map and reduce Barriers (friction preventing that behavior), and amplify Benefits (motivation to take the action). This framework, used with Google, PayPal, Facebook, and Netflix, distills hundreds of behavioral economics principles into a structured design process. The most common mistake teams make is optimizing the wrong behavior (solving for 'log in' instead of 'complete first meaningful action') or adding features (benefits) without removing friction (barriers) first.

## How to implement
- Define one specific, measurable, timed Key Behavior before any design work: 'User connects their calendar within the first session' not 'User engages with the product'
- Create a behavioral map of every click, field, decision, and step between current state and the Key Behavior — each step is a potential barrier
- Systematically eliminate barriers: reduce form fields, pre-fill data, eliminate redirect steps, simplify language, remove requiring account creation before value delivery
- Amplify existing benefits rather than manufacturing artificial ones: make the immediate value of the Key Behavior more visible and concrete
- Create new benefits where intrinsic motivation is insufficient: social norms, loss aversion framing, or direct rewards
- Run controlled experiments to validate barrier-removal and benefit-amplification interventions before full rollout

## Metrics
Applying this pattern can positively influence the following UX metrics:
- **Engagement & Usage**: Clickthrough rate, Feature usage, Active users
- **Revenue**: Conversion rate, Revenue per session
- **Adoption & Retention**: Signup completion rate, Account creation rate
**How to measure**: Map identified barriers and benefits to specific funnel steps; measure conversion rate and drop-off at each step via analytics before and after barrier-removal interventions, using A/B tests to isolate individual changes.

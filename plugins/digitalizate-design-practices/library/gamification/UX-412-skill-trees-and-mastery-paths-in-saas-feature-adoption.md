## Why
Skill trees — branching visual maps of learnable capabilities — give users a visible roadmap to mastery and create intrinsic motivation to explore adjacent skills. Salesforce Trailhead's learning path system, Duolingo's skill map, and RPG talent trees all use this pattern. In SaaS contexts, a skill tree can visualize feature adoption paths, certification tracks, or expertise levels, turning the overwhelming complexity of a feature-rich product into an engaging progression system.

## How to implement
- Map your product's feature set into a visual skill tree: group related features into 'skill branches' (e.g., 'Data Analysis', 'Collaboration', 'Automation') with dependencies
- Show locked and unlocked nodes clearly — users should see what they can learn next and what paths are available at their current skill level
- Unlock advanced skills only after demonstrating competence in prerequisites — this enforces a logical learning order while creating unlocking satisfaction
- Create certification or mastery designations at branch completion: 'SQL Analyst' certification after completing all SQL-related skills
- Allow users to choose which branch to develop first — supporting autonomy within a structured progression framework
- Show the 'meta-map': what does completing the full skill tree unlock? Give users a clear image of what mastery looks like
- Display social proof on skill nodes: 'Join 12,400 users who have mastered this skill' — making each node feel like a worthwhile milestone

## Metrics
Applying this pattern can positively influence the following UX metrics:
  - **Adoption & Retention**: Feature usage, Returning visitors, Renewed subscriptions
  - **Engagement & Usage**: Active users, Sessions per user, Session frequency
  - **Satisfaction & Perception**: CSAT, NPS, Ease-of-use score
  **How to measure**: Track feature adoption rates along defined skill tree paths and measure whether users who progress through mastery stages have higher retention rates than those who do not. Use cohort analysis to compare 30/60/90-day retention for users who unlock advanced features vs. those who remain at basic levels.

## Why
Different users within the same organization need different views of the same data. An inflexible dashboard forces a one-size-fits-none compromise that frustrates power users and overwhelms novices. Customizable dashboards create ownership and increase daily active use. Self-service customization — without IT involvement — is particularly important in enterprise contexts where implementation bottlenecks create long delays between user need and available configuration.

## How to implement
- Allow users to add, remove, and rearrange dashboard widgets.
- Save layout configurations per user across sessions.
- Provide multiple named "views" (Daily Ops View, Weekly Summary View).
- Allow widget-level filter customization (show only "my region" data in a specific module).
- Support team-level customization that can be shared without IT involvement.
- Provide template libraries teams can clone and adapt as starting points.

## Metrics
Applying this pattern can positively influence the following UX metrics:
- **Engagement & Usage**: Active users, Sessions per user, Feature usage
- **Adoption & Retention**: Returning visitors, Renewed subscriptions
- **Efficiency**: Time on task, Time saved per task
- **Satisfaction & Perception**: Ease-of-use score, CSAT
**How to measure**: Track the percentage of users who customize their dashboard at least once, and compare time-to-insight and session frequency between customizers and non-customizers in cohort analysis. Survey users who have personalized their layout on ease-of-use and overall satisfaction to confirm that customization drives measurable engagement gains.

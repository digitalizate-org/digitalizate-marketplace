## Why
The inverted pyramid is a writing structure from journalism adapted for web content: the most critical information (the conclusion, the key finding, the answer to the user's question) appears in the first sentence or paragraph, followed by supporting details in descending order of importance. NNGroup research shows that only 16% of users read web pages word-for-word; 79% always scan. The inverted pyramid serves all readers: scanners get the key point immediately; readers who continue get increasing context and depth. [GOV.UK](http://gov.uk/)'s content design guidelines mandate this structure because users read only 20–28% of page content.

## How to implement
- Open every page, article, section, and help document with the single most important statement — the answer to the user's likely question
- Write a summary paragraph (2–3 sentences maximum) above any long-form content; this summary should stand alone as a complete communication
- Within each paragraph, lead with the main point of that paragraph in the first sentence (a 'core sentence'), then support it
- Never use narrative build-up or background context before the key point: the user may leave before reaching it
- In error messages and system notifications, state the outcome or required action first, then explain why
- In product feature descriptions, lead with the user benefit ('Save 3 hours per week') not the feature description ('Our AI scheduler automatically…')
- Apply the 'cut from the bottom' test: if you deleted the last paragraph, would users still have the core information? If yes, the structure is correct

## Metrics
Applying this pattern can positively influence the following UX metrics:
  - **Efficiency**: Time on task, Completion time
  - **Engagement & Usage**: Scroll depth, Bounce rate
  - **Satisfaction & Perception**: Ease-of-use score, CSAT, Confidence rating
  **How to measure**: A/B test content structured with inverted pyramid (conclusion first) against traditional narrative structure, measuring time-to-key-information and bounce rate. Track task completion rates for decision-making tasks that rely on reading product or feature descriptions, confirming faster time-to-decision with lead-conclusion structure.

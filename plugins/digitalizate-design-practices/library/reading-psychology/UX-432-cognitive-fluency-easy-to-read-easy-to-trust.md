## Why
Cognitive fluency is the subjective sense of ease with which information is processed. Research in psychology (processing fluency studies) demonstrates that fluent information — easy to read, familiar in structure, clearly organized — is rated as more credible, more truthful, and more trustworthy than identical information presented in a disfluent form. Users experience cognitive ease as a positive emotional signal and interpret it as familiarity and competence. Conversely, cognitive strain from poor typography, cluttered layouts, or confusing navigation creates a negative signal of incompetence. Stanford research shows users form first impressions in 50 milliseconds, largely based on fluency signals.

## How to implement
- Use familiar, predictable interface patterns: place navigation where users expect it (top or left), use conventional button shapes, maintain consistent layout across pages
- Ensure high text contrast (minimum 4.5:1 for body text per WCAG AA) — low-contrast text is a direct cognitive disfluency driver
- Use simple, common vocabulary in interface copy; avoid jargon, technical terms, or unusual phrasing that forces users to decode meaning
- Maintain consistent typographic styling: the same heading level should always look the same, the same action type should always use the same label
- Minimize the number of cognitive choices on any screen — each additional choice option increases cognitive load and reduces fluency
- Test fluency: if users describe the interface as 'clean', 'simple', or 'professional' in usability testing, fluency is working; if they say 'confusing' or 'busy', investigate fluency breakdowns
- Use consistent spacing, alignment, and grid systems — visual consistency is a primary fluency signal

## Metrics
Applying this pattern can positively influence the following UX metrics:
- **Efficiency**: Time on task, Completion time
- **Satisfaction & Perception**: Confidence rating, CSAT, Brand perception
- **Revenue**: Conversion rate
**How to measure**: A/B test high-fluency layouts (clear fonts, adequate contrast, simple phrasing) against lower-fluency variants on landing or checkout pages, measuring conversion rate and confidence ratings. Use a brief post-task trust survey to capture the perceived credibility effect.

## Why
Systematic context orchestration with XML-like structuring, dynamic assembly, and failure prevention. The pattern: systematic context orchestration with XML-like structuring, dynamic assembly, and failure prevention. Provides enterprise-grade reliability and consistency for complex context management with standardized frameworks.
**Key insight:** Structured representation with modular components and validation enables reliable, scalable context engineering

## How to implement
1. **Schema Design** — Define XML-like structured context representation
1. **Orchestration Engine** — Build dynamic context assembly and coordination
1. **Validation Framework** — Implement coherence scoring and quality assessment
1. **Component Architecture** — Create modular, reusable context components
1. **Recovery Systems** — Build failure prevention and recovery mechanisms
- Example flow: `design_schema → orchestrate_dynamically → validate_coherence → modularize_components → prevent_failures`
- **Do:** Use structured XML-like formats for context representation; Implement semantic tagging and hierarchical organization; Build modular components for reusable context patterns; Use automated validation workflows for quality assurance; Implement comprehensive failure prevention mechanisms
- **Don't:** Use unstructured text without proper formatting; Skip validation of context coherence and quality; Create monolithic context without modular components; Ignore failure scenarios and recovery procedures; Hard-code context logic without framework flexibility

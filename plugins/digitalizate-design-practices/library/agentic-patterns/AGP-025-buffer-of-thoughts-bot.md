## Why
Maintains a dynamic buffer of reusable thought patterns for analogical reasoning. The pattern: thought-augmented reasoning that collects diverse approaches in a buffer, distills patterns, and creates reusable templates. Builds reasoning expertise over time by learning from diverse thought processes and creating reusable knowledge structures.
**Key insight:** Generate diverse thoughts → Buffer storage → Distill patterns → Create templates → Apply to new problems

## How to implement
1. **Thought Collection** — Generate diverse reasoning thoughts & approaches
1. **Buffer Storage** — Store thoughts in structured buffer memory
1. **Distillation** — Extract key insights and patterns from buffer
1. **Template Creation** — Create reusable reasoning templates
1. **Application** — Apply distilled knowledge to new problems
- Example flow: `Problem → Generate many thoughts → Store in buffer → Distill patterns → Create templates → Apply`
- **Do:** Encourage diverse and creative thought generation; Implement efficient buffer storage and retrieval; Focus distillation on actionable insights; Create templates that generalize across problems; Update buffer with new successful reasoning patterns
- **Don't:** Fill buffer with redundant or low-quality thoughts; Skip the distillation step (raw thoughts ≠ knowledge); Create overly specific templates without generalization; Ignore buffer capacity limits (memory overflow); Use stale templates without updating from experience

## Why
User education and onboarding patterns for introducing agent capabilities, building appropriate mental models, and fostering trust. The pattern: user education and onboarding patterns for building appropriate mental models and trust in AI agents. Users need proper introduction to agent capabilities to develop appropriate expectations and effective usage patterns.
**Key insight:** Build trust through progressive capability disclosure, hands-on practice, and transparent limitation communication

## How to implement
1. **Mental Model Building** — Establish clear agent capabilities and limitations early
1. **Progressive Disclosure** — Layer complexity from basic to advanced features
1. **Interactive Tutorials** — Hands-on practice with real agent interactions
1. **Trust Calibration** — Demonstrate reliability and failure scenarios
1. **Contextual Help** — Just-in-time assistance and feature discovery
- Example flow: `intro_capabilities → guided_interaction → trust_demo → practice_scenarios → ongoing_support`
- **Do:** Start with clear capability boundaries and limitations; Use progressive disclosure to prevent cognitive overload; Provide hands-on practice with immediate feedback; Build trust gradually through transparency and reliability; Offer contextual help and feature discovery prompts
- **Don't:** Overwhelm users with all features at once; Promise capabilities the agent cannot deliver; Use lengthy text-heavy tutorials without interaction; Hide important limitations or failure modes; Force users through rigid linear onboarding flows

## Metrics
Key metrics to track when applying this pattern:
  - Onboarding Completion (% of users completing initial training flow)
  - Feature Adoption (Rate of advanced feature discovery and usage)
  - Trust Calibration (Appropriate reliance on agent recommendations)
  - Time to Productivity (Duration from first use to effective task completion)
  - User Retention (% of users returning after initial onboarding)
  - Support Reduction (Decrease in help requests post-onboarding)
  **Proven use cases:**
  - AI Assistant Introduction: Progressive capability reveal with trust-building scenarios
  - Professional Tool Onboarding: Expert feature education with workflow integration
  - Consumer AI Products: Mental model building for everyday users
  - Enterprise Agent Deployment: Role-based training with compliance education
  - Educational AI Tutors: Learning methodology explanation and interaction patterns

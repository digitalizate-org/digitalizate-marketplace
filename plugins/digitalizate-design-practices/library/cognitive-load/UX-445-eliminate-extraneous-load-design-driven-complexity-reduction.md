## Why
Extraneous cognitive load is generated by how information is presented — not by the information itself. Poor layout decisions, inconsistent visual language, unclear labels, and irrelevant UI elements all add extraneous load that consumes working memory without advancing the user's goal. Reducing extraneous load is the single highest-leverage action a UI designer can take, because it directly frees cognitive resources for the user's actual task.

## How to implement
- Audit every UI element against the question: 'Does this help the user accomplish their goal, or does it exist for another reason (aesthetics, developer convenience, marketing)?' Remove anything that fails.
- Enforce a consistent design language across the entire application — same typography scale, color semantics, icon set, and interaction patterns throughout.
- Eliminate decorative animations that do not convey state or transition meaning.
- Replace complex paragraph instructions with labeled diagrams, numbered steps, or inline tooltips at the point of action.
- Use whitespace deliberately to group related elements and separate unrelated ones (Gestalt proximity), reducing the visual work of parsing structure.
- Run periodic 'cognitive load audits' using heuristic evaluation against Nielsen's 10 usability heuristics, focusing on heuristics #1 (visibility), #4 (consistency), and #8 (minimalist design).

## Metrics
Applying this pattern can positively influence the following UX metrics:
- **Efficiency**: Time on task, Error counts
- **Effectiveness**: Completion rate, Task success rate
- **Satisfaction & Perception**: Ease-of-use score, CSAT
- **Engagement & Usage**: Abandonment rate
**How to measure**: Conduct a cognitive load audit (heuristic evaluation + usability testing) to identify sources of extraneous load. After removing or reorganizing cluttered interface elements, measure task completion rate and time on task, and collect SUS or ease-of-use scores to confirm that complexity reduction produces a statistically meaningful improvement.

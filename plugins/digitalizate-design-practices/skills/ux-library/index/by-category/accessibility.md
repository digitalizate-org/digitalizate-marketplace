# Accessibility (13)

Reference: references/accessibility.md

- UX-001 · Color Contrast — Minimum 4.5:1 for Normal Text [Color contrast compliance] · ★5 · tags: accessibility · use: Apply to all text — labels, table cells, form fields, error messages, chart labels, navigation items. Test both light and dark modes independently.
- UX-002 · Never Rely on Color Alone to Convey Information [Color Accessibility] · ★5 · tags: data-heavy, dashboard, accessibility · use: Use when designing status indicators, data visualizations, charts, and any color-coded system.
- UX-003 · Full Keyboard Accessibility for All Interactive Elements [Keyboard navigation] · ★5 · tags: keyboard, navigation, accessibility · use: Apply to all interactive elements. Keyboard navigation is critical for users with motor impairments and is also the preferred method for many enterprise power users.
- UX-004 · Visible Focus Indicators [Focus Management] · ★5 · tags: keyboard, navigation, accessibility · use: Use for all interactive elements: links, buttons, inputs, custom components in all application states.
- UX-005 · Semantic HTML and ARIA Roles [Semantic Markup] · ★5 · tags: accessibility · use: Use for all UI component development — the foundation of accessible interface implementation.
- UX-006 · Keyboard Navigation with Tab Focus Management [Keyboard Accessibility] · ★5 · tags: desktop, keyboard, navigation, accessibility · use: Every enterprise application. Non-negotiable for WCAG AA compliance and a strong productivity feature for power users who prefer keyboard-first interaction.
- UX-007 · Keyboard-Navigable Modals and Focus Trapping [Modal Accessibility] · ★5 · tags: keyboard, navigation, accessibility · use: All modal dialogs, drawer panels, and dropdown menus across the application.
- UX-008 · Meaningful Alternative Text for Images and Data Visualizations [Screen reader accessibility] · ★4 · tags: data-heavy, accessibility · use: Apply to all images, icons, charts, and graphic elements. ALT text for data visualizations must describe the insight conveyed, not the chart type.
- UX-009 · Minimum Target Size — 44×44px [Touch and Click Targets] · ★4 · tags: mobile, accessibility · use: Use for all interactive controls, especially those in dense data tables, toolbars, and compact table row actions.
- UX-010 · Respect prefers-reduced-motion [Motion Accessibility] · ★4 · tags: animation, accessibility · use: Use for all CSS and JavaScript animations, transitions, and scroll-triggered effects in the application.
- UX-011 · Keyboard-Accessible Drag and Drop [Drag and Drop] · ★4 · tags: keyboard, accessibility · use: All drag-and-drop interactions. WCAG 2.1 SC 2.1.1 requires all functionality to be operable via keyboard — drag-and-drop without keyboard equivalents…
- UX-012 · Data Visualization Accessibility [Chart Accessibility] · ★4 · tags: data-heavy, accessibility · use: All charts, status indicators, heatmaps, and any visualization using color to encode data.
- UX-013 · Cultural Context in Color and Symbol Interpretation [Global Design] · ★3 · tags: — · use: Use when designing for international or global enterprise markets, and when choosing status colors and iconography.

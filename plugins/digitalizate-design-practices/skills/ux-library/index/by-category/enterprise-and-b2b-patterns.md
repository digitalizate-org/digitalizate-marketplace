"A little training is required" is not acceptable at consumer-grade UX standards.

Interruptions are not exceptional — they are the norm in enterprise work environments.
- UX-163 · Bulk Actions for Power Users [Batch Operations] · ★5 · tags: workflow, enterprise · use: Use in any data table or list where users regularly need to manage multiple items — CRMs, order management, content management systems.

- UX-167 · Comprehensive Audit Trail Architecture [Audit Trails] · ★5 · tags: enterprise, ai-patterns · use: All enterprise applications handling sensitive data, financial transactions, user management, or regulated content.

- UX-169 · Admin Panel Multi-Column Interface [Admin Panels] · ★5 · tags: enterprise, tables, navigation · use: All back-office and administrative interfaces. The multi-column structure is the established baseline for admin panel design in enterprise software.

- UX-171 · Coordinate Transitions Across Multiple Tools and Workspaces [Cross-tool integration and export] · ★4 · tags: enterprise · use: Apply to enterprise tools where users must combine data from multiple systems — analytics + spreadsheets + reporting, CRM + email + calendar.

- UX-184 · Print and Export Formatting [Output Formatting] · ★3 · tags: forms · use: All reports, audit logs, approval records, financial statements, and executive dashboards in enterprise applications.
